= Drop and Merge Documentation Repository

This repository contains the official documentation source for *Drop and Merge*.
It is a documentation-only repository built around Antora-compatible AsciiDoc, published as a static site to GitHub Pages.

The published site is available at https://bovinemagnet.github.io/drop-merge-docs.

== Source of Truth Policy

IMPORTANT: The Antora source files under `docs/` are the *source of truth*.
Generated files under `build/` are build artifacts and must not be edited manually.

== Site Theme

The site uses the Antora default UI, vendored as `ui-bundle.zip`, with branding applied through `supplemental-ui/`.
Antora merges those files over the bundle by path, so they either override a bundled file or add a new one.

`supplemental-ui/css/site-extra.css`:: Colour overrides. The palette is declared once in the `:root` block at the top; change it there to re-brand the site.
`supplemental-ui/partials/head-styles.hbs`:: Loads `site-extra.css` after the bundle's own stylesheet, so the overrides win.
`supplemental-ui/partials/footer-content.hbs`:: Site footer.

To take a newer upstream UI, replace `ui-bundle.zip` and rebuild.
The supplemental files are applied on top of whatever bundle is present, so branding survives the upgrade.

== Install Dependencies

[source,bash]
----
npm install
----

== Build the Antora Site

[source,bash]
----
npm run docs:build
----

Output is written to `build/site`.

== Preview Generated Output

Open `build/site/index.html` in a browser, or serve the directory over HTTP.

== Add a New Documentation Page

. Add a new page file to the relevant module under `docs/modules/`.
. Give it a document title (`= Page Title`).
. Add it to that module's `nav.adoc`.
. Link to it from related pages using Antora syntax (for example, `xref:my-page.adoc[My Page]`).
. Run `npm run docs:build` to validate.

Antora fails the build on broken `xref:` links and AsciiDoc syntax errors, so a successful build is the validation step.

== Publishing Flow

`.github/workflows/docs.yml` builds the Antora site on every push and pull request to `main`.
Pull requests build only, to validate the source.
Pushes to `main` deploy the built site to GitHub Pages.

GitHub Pages must be configured with *Source: GitHub Actions* for the deployment to succeed.
