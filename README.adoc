= Drop and Merge Documentation Repository

This repository contains the official documentation source for *Drop and Merge*.
It is a documentation-only repository built around Antora-compatible AsciiDoc, with a generation workflow for GitHub Wiki pages.

== Source of Truth Policy

IMPORTANT: The Antora source files under `docs/` are the *source of truth*.
Generated files under `build/wiki` are build artifacts and must not be edited manually.

== Repository Structure

[source,text]
----
.
├── README.adoc
├── antora-playbook.yml
├── package.json
├── docs/
│   ├── antora.yml
│   └── modules/ROOT/
│       ├── nav.adoc
│       ├── pages/
│       └── assets/images/
├── scripts/generate-wiki.mjs
└── .github/workflows/docs.yml
----

== Install Dependencies

[source,bash]
----
npm install
----

== Build the Antora Site

[source,bash]
----
npm run docs:build
----

Output is written to `build/site`.

== Generate GitHub Wiki Pages

[source,bash]
----
npm run wiki:generate
----

Output is written to `build/wiki`.

== Build Everything

[source,bash]
----
npm run docs:all
----

This builds the Antora site and then generates wiki pages.

== Preview or Inspect Generated Output

* Antora site: open files from `build/site`
* Wiki pages: inspect `.adoc` files in `build/wiki`

== Add a New Documentation Page

. Add a new page file to `docs/modules/ROOT/pages/`.
. Give it a document title (`= Page Title`).
. Add it to `docs/modules/ROOT/nav.adoc`.
. Link to it from related pages using Antora syntax (for example, `xref:my-page.adoc[My Page]`).
. Run `npm run docs:all` to validate build and wiki generation.

== Wiki Publishing Flow

The CI workflow builds and uploads artifacts for:

* Antora site (`build/site`)
* Generated wiki files (`build/wiki`)

An optional, commented section in `.github/workflows/docs.yml` shows how to sync `build/wiki` to the repository wiki. Enable it only after configuring permissions and validating your process.

== Antora vs Generated Wiki Docs

* *Antora source docs*: authored and reviewed by documentation contributors (`docs/`)
* *Generated wiki docs*: produced by `scripts/generate-wiki.mjs` (`build/wiki`)

Do not manually edit generated wiki files. Always update Antora source and regenerate.
