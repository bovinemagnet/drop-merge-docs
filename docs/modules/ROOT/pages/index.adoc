= Drop & Merge

Welcome to the player guide for *Drop & Merge* — a drop-and-merge puzzle game: drop pieces into a jar, match them, and merge your way up an ever-growing ladder.

Drop & Merge is a *family of games*. Every edition — Fruit, Norse myth, K-pop idols, the Chinese zodiac and more — plays in exactly the same way; only the theme changes. Learn one and the skills carry across all of them.
